## 本轮交付

### 持币样本付款

- 发币向导、签名前规则、Treasury 和公开项目披露均说明使用 explorer 返回样本；不再把它表现为完整的全体持有人分红。
- 新付款审核展示来源、UTC 读取时间、固定区块是否已建立、分页情况、返回行数、去重数、有效样本及实际计算分母。链上读取的 token decimals 用于显示单位；未知不默认 18。
- 首次准备只返回预览，不返回可签名 calldata。只有同一个、尚未过期且绑定 owner/project/token/vault 的 review 被明确接受样本范围后，服务端才允许返回模拟通过的交易。
- 样本与名单金额冻结；相同地址相同余额去重而不累加，冲突重复/非法余额拒绝。遗漏的持有人本轮不收款，也没有为其保留计算外的“应得份额”。
- 明确区分最低门槛、200 人限制和手工排除后的未付款；最大余数算法会分配舍入余数，不额外声称存在舍入留存。
- 审核后金库余额下降或已有新付款轮次时要求重新读取。额外入金不改变原名单或金额，并单列为本轮未分配入金。
- 前端名单变化阻止签名；重查一开始清除旧 calldata，重查失败也不能使用旧交易。模拟失败、过期、未接受样本范围都阻止钱包确认。
- CSV 导出保留样本覆盖与分母说明；最终资金交易仍需用户钱包签名。

主要代码：`server/market.mjs`、`shared/distribution.mjs`、`server/pons.mjs`、`src/PayoutCoverage.tsx`、`src/TreasuryWorkspace.tsx`。

### MATE 运营闭环

发现并修复了观察等待期间的取消边界：运营复盘在等待链上观察/上下文时，用户暂停或修改项目记忆，先前仍可能继续启动付费生成。现在在用量预留与供应商调用之前重新检查该轮 contextVersion，已过时的复盘不再启动生成。

新增离线跨模块测试通过真实本地 API 证明：

1. 钱包登录后无项目聊天可用，聊天不会自动创建项目。
2. 用户通过既有项目 API 显式创建项目，通用聊天不会被非法绑定成项目上下文。
3. MATE 生成内容日历和活动的私人提案，编辑后仍须明确确认；过期 revision 拒绝，重复应用不重复创建记录。
4. 内容完成结果与手工 X 链接/指标保留创作者报告、未验证的来源语义，活动仅创建私人草稿，不伪造未公开活动的出席结果。
5. 后续复盘能读取该项目的实际记录；其他钱包/项目和无关私人通用聊天内容不进入上下文。
6. 只观察不调用供应商；暂停、修改记忆、额度及默认调度边界有回归。

供应商响应全部使用测试桩。这里验证的是软件闭环，不是新一次真实 AI 或 X 账号验收。
