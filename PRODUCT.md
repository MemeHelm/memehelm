# MemeHelm

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

English-speaking memecoin creators and community operators on Robinhood Chain. A project may be launched through MemeHelm or imported for private tracking.

## Product Purpose

Help creators continue operating a project after issuance: retain its context, observe available changes, review useful actions, share approved updates and record actual outcomes. The user approved extending AI Copilot beyond on-demand writing into this workflow.

## Operating Context

The current release runs locally. Hosting is deferred until the user supplies an environment. Wallet sign-in protects private project data. Users review and sign financial actions themselves. pons v2 provides issuance and trading on Robinhood mainnet 4663.

## Capabilities and Constraints

Existing launch, trading, fixed ETH split, project-page publication, watchlist, writing and editing flows remain. Operations adds persistent project memory, bounded observations, proposed task/update actions, explicit approval, task outcomes, an activity journal and a persistent daily request allowance. Observation and scheduled AI reviews are separately opt-in; new projects are paused. Community adds shared social links, event invitations, authenticated registration, attendance and creator recaps. X OAuth and reviewed publishing are implemented with encrypted server-side tokens, but require application credentials and real-account acceptance; no automatic social posting is provided. Discord/Telegram are community entry links. No autonomous market making, cross-chain issuance, signing key custody or automatic financial execution is included.

Community goals add private instructions, explicit public snapshots, wallet-signed participation, creator review, optional public contributions and nonfinancial points. Goals can close with private or shared recaps; withdrawal removes a contribution's public entry and points. The content calendar holds private channel drafts and manual outcomes for future reviews. Meme Studio composes local images and captions for PNG export; it is not an AI image generator. Today brings priority actions, contribution reviews, upcoming content/events, bounded holder evidence and recorded outcomes together. Creators can explicitly share a task's title and outcome without its private instructions. These capabilities do not provide external social analytics, autonomous publication or cloud monitoring.

## Brand Commitments

MemeHelm, the angular M mark and “Launch it. Steer it.” The user selected a desktop with movable windows, shortcuts and a taskbar, using the existing near-black, cold-white and citron brand. User-facing copy is English. Internal implementation status, provider settings and secrets stay out of the product.

## Evidence on Hand

The repository contains protocol/fork, wallet/session, API and UI verification records. These do not establish an independent audit, public deployment, real funded user acceptance or continuous third-party service availability. Observations must state coverage and missing data. Examples must be labeled.

## Product Principles

- Preserve creator ownership and explicit publication consent.
- Distinguish observed facts, creator notes and AI suggestions.
- Make review, execution and outcomes a connected workflow.
- Keep budgets, pauses, failure recovery and private data boundaries visible and functional.
- Retain the established visual system and existing features.
