# Quality bar — MemeHelm OS

An Operate surface, retaining the user's chosen OS form. This records the approved direction's evaluation bar; it is not a fabricated concept-seed result.

- **World:** graphite desk, original relief M with citron notch, silver tool icons and calm translucent window chrome.
- **First viewport:** closed desktop, nine labeled shortcuts in height-responsive columns at left, thin top bar, floating Dock below; the brand opens Workspace. Phones use a three-column grid.
- **Working composition:** independent task windows. Workspace carries real project identity, next actions and an honest project shelf. Primary controls are obvious; supporting labels remain readable.
- **Signature behavior:** launch, minimize, restore and close connect each app to its Dock identity. Pointer hover has quiet feedback. Three points wander independently with pause, hidden-tab and reduced-motion handling.
- **Cross-surface reach:** launch, project library, Copilot, Treasury, discovery, signals, calculator, guide and search inherit one material/type/spacing language. All existing entry points remain accessible.
- **Responsive proof:** a complete desktop and reachable tools at 1440, 1024, 768, 390 and 320 CSS pixels; phone windows fill the usable surface and scroll internally.
- **Truth:** no invented balances, launches, users or AI output. Wallet and publication boundaries are unchanged. The visual review does not assert funded mainnet acceptance.
- **Honest risk:** the OS metaphor can hide tools from a new visitor; clear shortcut labels, Apps, the global search and Quick Guide must compensate. Small chrome must stay operable and visible on narrow screens.

Critique references and user quotes are recorded in `.impeccable/os-direction.md`.
